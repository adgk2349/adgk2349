### 2) FlowMap: Visualizing Code Structure and Change Impact During AI Coding
- Repo: [FlowMap-AI_Code_Hallucination_Guard_for_Swift](https://github.com/adgk2349/FlowMap-AI_Code_Hallucination_Guard_for_Swift)
- Built after repeatedly seeing AI coding assistants lose track of variable names or drop previously implemented features in long conversations — lets developers inspect code structure and relationships directly via a graph view.
- Core engine written in Rust for fast analysis; a later update fixed a right-click regression that only appeared in the packaged VS Code extension and improved node-overlap readability in the graph.
